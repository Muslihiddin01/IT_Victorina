# IT Викторина

Сайт для тестов на уроке. Учитель создаёт комнату, ученики входят по коду, учитель запускает тест,
и у всех одновременно начинается таймер. После начала теста интернет можно выключить: вопросы уже
на устройстве ученика. Учитель видит, кто уходил со страницы и кто включал интернет.

## Как устроен проект

```
src/
  app/
    login/          вход (для всех)
    join/           ученик вводит код комнаты
    test/           сам тест: лобби → загрузка → вопросы → отправка → результат
    admin/          панель учителя: комнаты, ученики, вопросы
    api/            сервер: все запросы к базе данных
  lib/
    db.ts           подключение к базе (Neon на Vercel, PGlite на своём компьютере)
    schema.ts       таблицы базы
    seed.ts         первые вопросы по урокам 1–7 и основам HTML/CSS/JS
    auth.ts         вход, сессии, проверка прав
    rooms.ts        комнаты: код, подбор вопросов, участники
    test-storage.ts сохранение теста в браузере (работа без интернета)
  components/       кнопки, иконки, рамка админки
public/sw.js        service worker: страница теста открывается даже без интернета
```

## Запуск на своём компьютере

```bash
npm install
cp .env.example .env.local   # и впиши свой логин и пароль
npm run dev
```

Открой http://localhost:3000 и войди как админ. База данных создастся сама в папке `.data/`.
Офлайн-перезагрузка страницы теста работает только в рабочей версии (на Vercel), в `npm run dev` она выключена.

## Переменные окружения

| Переменная       | Зачем                                                        |
| ---------------- | ------------------------------------------------------------ |
| `ADMIN_LOGIN`    | логин учителя                                                |
| `ADMIN_PASSWORD` | пароль учителя (поменял и сделал Redeploy — пароль обновился) |
| `ADMIN_NAME`     | имя учителя на сайте                                         |
| `DATABASE_URL`   | база Postgres; на Vercel её добавляет интеграция Neon        |
| `TIMEZONE`       | часовой пояс для файла с результатами, по умолчанию `Asia/Dushanbe`           |

## Как добавить сразу много вопросов

Админка → «Вопросы» → «Добавить списком». Между вопросами — пустая строка:

```
# Урок 8. HTML
? Какой тег делает ссылку?
+ <a>
- <p>
- <img>
! Тег a — от английского anchor, «якорь».
```

`#` — тема (если такой нет, она создастся), `?` — вопрос, `+` — правильный ответ, `-` — неправильные,
`!` — пояснение для разбора ошибок (можно не писать). Если в списке есть ошибка, сайт покажет номер строки
и не добавит ничего, пока её не исправить.

## Таджикский язык

Ученик выбирает язык переключателем «Рус | Тоҷ» (на входе, в комнате и прямо во время теста) — выбор
запоминается на устройстве. Админка остаётся на русском.

У каждого вопроса есть необязательный перевод: в редакторе справа от русского поля — таджикское, варианты
идут парами (вариант Б по-таджикски — перевод варианта Б). Если перевода нет, ученик видит вопрос по-русски
с пометкой «Тарҷума нест». Фильтр «Только без таджикского перевода» показывает, что ещё не переведено.
Первые 74 вопроса уже переведены (`src/lib/seed-tj.ts`).

Кнопка «Перевести на таджикский» в редакторе заполняет пустые таджикские поля автоматически (бесплатный сервис
MyMemory, без ключа). Уже заполненное не трогает. Перевод машинный — проверьте его перед сохранением. Лимит —
около 5000 символов в день (примерно 15–20 вопросов); если добавить в Vercel переменную `MYMEMORY_EMAIL` с любой
своей почтой, лимит вырастет до 50 000.

## Результаты в Excel и оценки

Оценки ставятся от 5 до 0 по проценту правильных ответов. Обычные пороги:

| Оценка | Процент | Из 20 вопросов |
|---|---|---|
| 5 | от 85 % | 17–20 |
| 4 | от 70 % | 14–16 |
| 3 | от 50 % | 10–13 |
| 2 | от 30 % | 6–9 |
| 1 | от 15 % | 3–5 |
| 0 | меньше 15 % | 0–2 |

В комнате кнопка «Скачать результаты (Excel)» отдаёт файл `.xlsx`. Рядом — «Оценки: 85/70/50/30/15%»: там пороги
можно поменять (запоминаются в браузере). Оценка видна и в таблице учеников комнаты. В самом файле пороги стоят в жёлтых
ячейках вверху листа: поменяете их в Excel — колонка «Оценка» и счётчики «Получили «5»» пересчитаются сами.
Кто не сдал, оценку не получает (пустая ячейка, а не 0).

## Печатание на скорость

Как на monkeytype, но проще: случайные английские слова, таймер 30 или 60 секунд, результат — слов в минуту
(«слово» = 5 символов, считаются только правильно напечатанные слова). Точности в процентах пока нет.

- **Тренировка:** «Тренировка» → «Печатание на скорость». Таймер запускается с первой буквы, лучший результат
  запоминается на устройстве.
- **Тест от учителя:** «Новая комната» → «Печатание» → 30 или 60 секунд. Ученики входят по коду как обычно, у всех
  одинаковые слова, попытка одна. Скорость пересчитывает сервер по присланным словам, поэтому подделать её нельзя.
  В таблице комнаты и в Excel — слов в минуту, самые быстрые сверху; в журнале ученика — тоже.

## Журнал успеваемости

«Ученики» → «Журнал» (или клик по имени): все тесты ученика, его оценки, средний результат, рост (последние тесты
против первых) и график — процент в каждом тесте, пунктиром пороги оценок. Наведите на точку — увидите тест и баллы.

## Картинки в вопросах

В редакторе вопроса — «Добавить картинку» или просто вставьте скриншот через Ctrl+V. Большое фото с телефона браузер
сам уменьшит до 1200 px. Картинки хранятся в базе (таблица `images`), одна и та же картинка — один раз. Ученик скачивает
их вместе с тестом, поэтому после выключения интернета они тоже видны.

## Тренировка

У ученика сверху меню: «Тест по коду» и «Тренировка». В тренировке он в любое время выбирает тему (или «Все темы
вместе» — 20 случайных вопросов из всех уроков) и сразу после ответа видит, правильно ли, и пояснение. Оценки и
времени нет, учителю результаты не отправляются.

## Как работает офлайн-режим

1. Учитель нажимает «Начать тест». Браузер ученика скачивает все вопросы **без правильных ответов**.
2. Ученик выключает интернет. Ответы сохраняются в `localStorage` после каждого нажатия.
3. Браузер следит за событиями `online`, `blur`, `visibilitychange` и считает нарушения.
4. Ученик нажимает «Завершить», включает интернет, ответы уходят на сервер, и **сервер** считает баллы.
5. Разбор ошибок открывается ученикам только после того, как учитель завершит тест для всех.
