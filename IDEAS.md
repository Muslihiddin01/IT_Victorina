# Идеи для викторины

Список улучшений на будущее. Сделанное отмечено галочкой.

## Быстро и с большой пользой

- [x] **Статистика по вопросам.** После теста учитель видит, какой вопрос завалил весь класс, — значит, тему стоит объяснить заново.
- [x] **Ответы ученика для учителя.** Клик по ученику в таблице открывает его разбор: что выбрал, где ошибся.
- [x] **Продление времени.** Кнопки «+1 мин» и «+5 мин» во время теста (для всех сразу).
  - [ ] Продление для одного ученика.
- [ ] **Повтор теста.** «Создать такую же комнату» с теми же темами и настройками в один клик.
- [ ] **Пояснение к вопросу.** Учитель пишет, почему ответ правильный, ученик видит это в разборе.
- [ ] **QR-код комнаты.** Ученик наводит камеру и сразу попадает на ввод кода.

## Удобство для учителя

- [ ] **Группы и классы.** Ученики по классам (7А, 8Б), в комнату можно пустить только свой класс.
- [ ] **Журнал успеваемости.** Страница ученика со всеми его тестами и графиком роста.
- [ ] **Импорт вопросов** из Excel или текста.
- [ ] **Картинки в вопросах.**
- [ ] **Оценка по 5-балльной шкале** в Excel: учитель задаёт пороги процентов.

## Интереснее для учеников

- [ ] **Режим игры.** Все отвечают на один вопрос одновременно на время, на экране учителя — таблица лидеров.
- [ ] **Тренировка.** Ученик сам проходит вопросы по теме без оценки и сразу видит правильный ответ.
- [ ] **Другие типы вопросов.** Несколько правильных ответов, ввод короткого ответа, расставить по порядку.
- [ ] **Достижения.** Например, «5 тестов подряд без ошибок».

## Надёжность и безопасность

- [ ] **Автоматическая резервная копия** результатов раз в неделю на почту или в Google Drive.
- [ ] **Защита от подбора паролей**, но так, чтобы одноклассник не мог заблокировать чужой аккаунт.
- [ ] **Автотесты**, которые запускаются при каждом push.
- [ ] **Смена пароля учителя прямо на сайте**, а не через настройки Vercel.

## Если проект станет большим

- [ ] **Несколько учителей** — у каждого свои ученики, комнаты и вопросы.
- [ ] **Языки:** таджикский и русский интерфейс.
- [ ] **Приложение на телефон (PWA):** значок на рабочем столе.
